# Manjaro Forum Sample Collector — Prototype 4

Student-facing two-stage acquisition interface for the deployed Cloudflare Worker.

## Test locally

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Under **DRAW GENERAL SAMPLE**, click **Collect Sample 1**. Confirm 100 topics appear and download the CSV.
4. Under **DRAW NAMED-ENTITY SAMPLE**, enter `wine` and click **Collect Sample 2**. Confirm up to 100 Wine-tagged topics appear and download the CSV.
5. Import both CSV files into Google Sheets and verify the columns and topic URLs.

The application acquires data only. Students remain responsible for sorting, coding, classification, analysis, interpretation, and recommendations.
